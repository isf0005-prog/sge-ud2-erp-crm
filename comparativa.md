## 2. Licencias y modelos
Software libre (FSF)

Explicado fácil:

El software libre permite al usuario utilizar, estudiar, modificar y compartir el programa respetando las condiciones de su licencia.

Importante:

Software libre NO significa necesariamente gratis.

Código abierto (OSI)

Puedes poner:

El código abierto permite acceder al código fuente y utilizarlo, modificarlo y redistribuirlo según las condiciones de una licencia aprobada por la Open Source Initiative (OSI).

Software propietario

Puedes poner:

El software propietario está controlado por una empresa o propietario que establece las condiciones de uso. Normalmente no permite modificar o redistribuir libremente su código fuente.

¿Libre = gratis?

Pon una explicación sencilla:

No. Que un programa sea libre se refiere principalmente a las libertades que proporciona al usuario sobre el software, no a que necesariamente tenga precio cero. Un programa puede ser gratuito y no ser software libre.

Esto es importante porque la rúbrica dice específicamente que si confundes libre con gratuito, pierdes puntos.

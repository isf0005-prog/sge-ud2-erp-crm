# Comparativa ERP-CRM

Licencias y modelos

Aquí tienes que explicar qué tipo de software es cada uno y qué significa su licencia.

Software libre

Es software que permite estudiar, modificar y compartir el programa según las condiciones de su licencia.

Código abierto (Open Source)

El código fuente está disponible y se permite modificar y distribuir el software siguiendo su licencia.

Software propietario

El código y los derechos de uso están controlados por una empresa. Normalmente hay que pagar una licencia o suscripción y existen más restricciones para modificar o distribuir el programa.

Importante

Software libre no significa necesariamente software gratuito. Una licencia puede permitir usar, modificar y compartir un programa y, aun así, existir servicios o versiones de pago.

Por ejemplo, Odoo Community 19 utiliza LGPLv3, mientras que Odoo Enterprise utiliza la licencia propia de Odoo Enterprise y requiere una suscripción válida.

En Microsoft Dynamics 365 Business Central, las licencias son de pago y existen diferentes modalidades para los usuarios, como Essentials, Premium y Team Member.
